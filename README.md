# PF1
## Pràctica 1 - PMM

### Context i objectiu

Treballes a l'equip de backend/lògica d'una startup de mobilitat sostenibilitat anomenada EcoRide. Abans de desenvolupar la interfície gràfica en Flutter, l'equip de producte necessita que programis el motor de lògica en Dart per gestionar la flota de vehicles (patinets, bicis i cotxes elèctrics) i el càlcul de tarifes dels usuaris.
